# DICOM dictionary tables: source and licence

`src/dict_data.rs` (the data dictionary and UID registry) and `src/deid_table.rs` (the
de-identification table) are generated by `scripts/update-dicom-dict.py`. Never edit them by
hand: change the script and rerun it. `src/dict.rs` is the hand-written API over them
(`dict::lookup`, `dict::by_keyword`, `dict::uid`, `dict::deid::ROWS`...).

## Source

The DocBook XML of the DICOM standard, edition **2026d** (the current edition when generated,
2026-11-09), published by NEMA:

| document | URL | tables used | SHA-256 |
|---|---|---|---|
| PS3.6 Data Dictionary | https://dicom.nema.org/medical/dicom/current/source/docbook/part06/part06.xml | 6-1 data elements, 7-1 file meta elements, 8-1 directory structuring elements, 9-1 dynamic RTP payload elements, A-1 UID values | `fa9f0f8d67eba692dcf95cfeae0a8f4e071beeb7844215a860bc4b9d5dfaad25` |
| PS3.7 Message Exchange | https://dicom.nema.org/medical/dicom/current/source/docbook/part07/part07.xml | E.1-1 command elements, E.2-1 retired command elements | `979da8b222a47d80260a5463ad1c2767bcc7966b6c5c2893daefedbd6c99b3df` |
| PS3.15 Security and System Management Profiles | https://dicom.nema.org/medical/dicom/current/source/docbook/part15/part15.xml | E.1-1 Application Level Confidentiality Profile Attributes | `1eb2a9724822476b3f1f3de23d15ae655a4c7f6e9d32bf16f2d9ef76d7d8437c` |

The script checks the edition named in each document's subtitle and the pinned SHA-256, and
aborts without writing on any mismatch.

Contents: 5258 plain data elements and 88 repeating-group or range elements (`(60xx,3000)`,
`(0028,04x0)`, `(1000,xxx0)`...), 468 registered UIDs, and 657 rows of PS3.15 Table E.1-1.
Left out: private tags, the item and delimiter tags `(FFFE,xxxx)` (PS3.6 gives no VR; the
codec handles them), and retired placeholders listed without a name or VR. In the
de-identification table the row "(gggg,eeee) where gggg is odd" (all private attributes) is
written with `tag` and `mask` 0x0001_0000, so it matches any odd group.

## Licence

The DICOM standard is © NEMA (National Electrical Manufacturers Association) and is freely
available from https://www.dicomstandard.org/ and https://dicom.nema.org/. The tables here
reproduce facts from it (tags, keywords, names, VRs, VMs, UIDs and de-identification action
codes) needed to implement the standard, as every DICOM toolkit does: pydicom, dcm4che, DCMTK
and dicom-rs all generate their dictionaries from the same DocBook source. No prose of the
standard is copied.

## Refreshing

NEMA publishes several editions a year (2026a to 2026d so far). At every release:

1. Set `EDITION` in `scripts/update-dicom-dict.py` (and `BASE` to
   `https://dicom.nema.org/medical/dicom/<edition>/source/docbook` once the edition is archived
   there; `current` moves with each release).
2. Run `python3 scripts/update-dicom-dict.py --print-digest`, check the digests, and put them in
   `DIGESTS`.
3. Run `python3 scripts/update-dicom-dict.py`, then `cargo test -p cameleer-dicom`.

`--source DIR` reads `part06.xml`, `part07.xml` and `part15.xml` from a local directory instead
of downloading them.
