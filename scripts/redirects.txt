# Pages that moved: `old-path new-path`, one per line, both site paths from the root.
#
# scripts/build-docs.py writes a redirect stub at every old path: an absolute canonical, a
# JavaScript location.replace that keeps the query and the #fragment, a 0-second meta refresh and
# a visible link. No noindex (it conflicts with the canonical). Stubs are kept forever: published
# crates, images, release notes and other sites link to old URLs.
#
# The build fails when a real page renders at an old path, when a target does not exist, or when a
# target is itself an old path (a chain). scripts/check-site.py checks the stubs again after the
# build, and crates/cameleer-main/tests/docs_harness.rs rejects links to old paths in the repo's
# markdown. Plan: docs/design/site-restructure/plan.md.
