Run your first route in a minute.

    
Use the container, the Rust crates or the CLI. Every example here is a file in the repository, run end to end by the test suite.


    

      
      
      
    


    

      

        
    
          
  1. Save a Camel YAML route as hello-api.camel.yaml
    2. 
          
  2. Run it in the container
    docker run --rm -p 8080:8080 \
  -v "$PWD:/routes:ro" pmsudhi/cameleer \
  run /routes/hello-api.camel.yaml
    3. 
          
  3. Call it
    curl localhost:8080/orders/42
{"id": "42", "status": "shipped"}
    4. 
        

        

          
hello-api.camel.yaml


- rest:
    path: /orders
    get:
      - path: /{id}
        to: direct:getOrder
- route:
    from:
      uri: direct:getOrder
      steps:
        - setBody:
            simple: '{"id": "${header.id}", "status": "shipped"}'

        

      

      
One native binary on distroless, for linux/amd64 and linux/arm64, non-root and fine with --read-only. On Docker Hub and as ghcr.io/pmsudhi/cameleer. Routes written for Apache Camel's YAML DSL run unchanged. Kubernetes and Cloud Run: deployment guide.

    


    

      

        
    
          
  1. Add the crates to Cargo.toml
    [dependencies]
cameleer-core = "0.3"
cameleer-http = "0.3"
    2. 
          
  2. Write routes in the Rust DSL (right)
    3. 
          
  3. Run and call it
    cargo run --release
curl localhost:8080/api/greet/Ada
    4. 
        

        

          
src/main.rs


use cameleer_core::prelude::*;
use cameleer_http::rest::RestDslExt;

fn main() -> Result<()> {
    let ctx = CamelContext::new();
    cameleer_http::register(&ctx);
    ctx.properties().set("camel.server.port", "8080");
    ctx.add_routes(|b| {
        b.rest("/api/greet").get("/{name}").to("direct:greet");
        b.from("direct:greet")
            .set_body(simple(r#"{"greeting": "Hello, ${header.name}!"}"#));
    })?;
    ctx.start()?;
    loop { std::thread::park(); }
}

        

      

      
To run YAML routes with every component from your own binary, depend on cameleer-main and call cameleer_main::new_main() (embed_yaml.rs).

      The AI ticket triage route

- route:
    id: ticket-triage
    from:
      uri: "kafka:support-tickets?brokers={{env:KAFKA_BROKERS:localhost:9092}}&groupId=triage&autoOffsetReset=earliest"
      steps:
        - setProperty:
            name: ticket
            simple: "${body}"
        - to: "openai:chat-completion?model={{env:OPENAI_MODEL:gpt-4o-mini}}&baseUrl={{env:OPENAI_BASE_URL:https://api.openai.com/v1}}&temperature=0&systemMessage=Classify the support ticket. Reply P1 for outages, data loss or security issues, otherwise P3. Reply with P1 or P3 only."
        - setHeader:
            name: priority
            simple: "${body}"
        - setBody:
            simple: "${exchangeProperty.ticket}"
        - choice:
            when:
              - simple: "${header.priority} contains 'P1'"
                steps:
                  - to: "kafka:tickets-urgent?brokers={{env:KAFKA_BROKERS:localhost:9092}}"
            otherwise:
              steps:
                - to: "kafka:tickets-routine?brokers={{env:KAFKA_BROKERS:localhost:9092}}"
